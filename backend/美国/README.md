# 美国（backend/美国）

美国服务器上的数据和代码：比赛数据的正本、每晚流程、AI 总管。

```
美国/
  db/          比赛库：比赛、届次、来源、处理记录、后台记录、拒过的网址（读写方法用 共用/db）；db/新维护/ 是比赛库的维护模块（db/维护/ 只剩每日归档）
  pipeline/    寻找新比赛：只有启动按时间触发，6 个模块按顺序跑，审核过的由 06 入库写进比赛库
  web/         抓网页：只给一个总函数 读网页，寻找和维护都要用，只经 web/index.mjs
  程序审核/    字段规则：标题闸、范围闸、资料齐不齐、收录门槛（含 AI 再判）、发布门槛；寻找、维护、后台发布都调，只经 程序审核/index.mjs
  （补字段/ 2026-11-12 删了：原来只有旧 AI 审查调用，随它一起删）
  ai/          AI 总管：DeepSeek、Kimi、百度、Jev、Codex（在美国本机调用）的统一调用、重试、记账
  定时/        美国服务器上的定时器配置：每晚流程 1:00、新维护 10:00、后台多选的维护队列每 2 分钟看一眼、回收站清理 0:30（北京时间）
  后台/        管理员用的网页：比赛数据总览、比赛管理、日志、流程监测、用户反馈（现在是框架）
```

- 寻找和维护互不引用，只通过比赛库来往。
- 每晚流程读不到的国内网页，以后可以经 `沟通/代读网页/` 请北京代读（2026-11-01 定先不做）；已公开的比赛经 `沟通/公开比赛同步/` 推给北京。
- 北京的用户数据经 `沟通/用户数据同步/` 同步一份只读副本过来，方便重构和后台审查。
- 这里只用自己的文件和 `共用/`，不引用 `北京/`。
