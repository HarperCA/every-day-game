# 平台

针对性平台搜索脚本的集成接口：计划里列的平台同时跑，一个平台失败只记问题，别的照收。

```
平台/
  index.mjs       调用平台(计划, ctx)：集成接口
  平台清单.mjs    登记了哪些平台
  天池/           天池的比赛列表接口（页面是动态加载的，走接口）        占位
  辽宁/           辽宁省大学生创新创业平台的公开数据接口（经北京代读）  占位
```

- 每个平台脚本：`(ctx) → [{ 标题, 网址, 摘要 }]`。加平台：建一个文件夹，在 `平台清单.mjs` 里登记。
- 读网页的通用步骤用 `ctx.web`（美国/web），不复制。
- 2026-10-31 从 `美国/web/tools/` 挪过来：这两个脚本只给搜索用。
