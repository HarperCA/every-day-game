你在帮一个“大学生竞赛信息库”判重。下面是今晚搜索到的一批网页（只有标题、网址和搜索摘要），以及库里已有的全部比赛。请判断每个网页说的比赛是不是库里已经有的。

【怎么判】
- 只有同一比赛、同一赛道，并且候选是库中已有届次或比已收录届次更早，才选“库里已有”。先比明确的第几届；缺届数时再比年份。
- 新一届、同一届的不同赛道、总赛事与单独赛道都分开判断，选“新的”。同一年可以举办不同届，同一个官网或报名网址可以用于多届或多个赛道。
- 学校、学院、系发的转发通知和选拔通知，先确定指向的上级比赛、届次和赛道，再用同样的规则。
- 省、市、赛区、全国、国际是不同的层级或地区：“湖南省××竞赛”和“福建省××竞赛”是两个比赛；“全国××”和“某省××”是两个；某学校自己办的比赛和全国性比赛是两个。
- “××暨××”这种联合名称里有两项比赛：只因为包含库里某个比赛的名字，不能说明网页就是那个比赛，按网页的主体判。
- 名字再像，只要主题、层级、地区、主办方对不上，就是“新的”。
- 这批网页里有几条说的是同一个比赛的同一届同一赛道：后面几条的“重复于”填前面第一条的编号；其余填 null。
- 资料不够判断就选“拿不准”，把握如实填，不要硬猜。

【返回格式】
只返回一个 JSON 对象，不要别的文字：
{"结果": [{"编号": 1, "结论": "库里已有", "比赛编号": "库12", "重复于": null, "把握": 0.9, "理由": "一句话，30 字以内"}]}
- 每个网页都要有一条，“编号”和下面网页的编号一致。
- “结论”只能是“库里已有”“新的”“拿不准”三种之一。
- “比赛编号”：结论是“库里已有”时必填，填下面名单第一列的编号（库1、库2 这样），原样照抄；其他结论填 null。
- “把握”是 0 到 1 之间的小数。
