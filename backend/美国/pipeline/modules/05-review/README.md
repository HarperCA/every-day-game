## 三项核验什么算过

搬自 `adminData/competitionAiReview.js` 的 runFieldVerification（提示词、三种日期状态）和 `intakeSchedule.js` 的 applyFieldVerification：

| 项 | 过 |
|---|---|
| 名称、报名网址 | 对；或不对但给了改正值（照改） |
| 报名开始、截止 | 一致；原文没写（清空，落回“时间待公布”，不算错）；或不一致但给了有效的改正值（照改） |
| 专业分类 | 有把握，且至少一类（十三类之内） |
| 来源性质 | 官方（学校转发的不算） |
| 来源正文 | 至少读到一个；一个都没读到不调 AI，直接没过 |

过了以后，读到的来源记成核验过的官方来源（`is_official`、`validity_status: valid`、标题、摘要、原文摘录、核验说明、支撑哪些字段、核验时间），06 入库的发布门槛要用。
