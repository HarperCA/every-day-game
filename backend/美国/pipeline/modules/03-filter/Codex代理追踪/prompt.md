- 找到官方来源：找到并读过比赛自己的官方来源（追到上级比赛的官方来源也算）。
- 不是比赛：不是值得收录的比赛。
- 只是赛区或校内选拔：而且追不到上级比赛的官方来源（理由里写上级比赛名）。

- 读不出内容：找到了官网，但读不出内容。
