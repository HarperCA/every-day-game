# 流程内复用（pipeline/common）

只给每晚流程的模块用、而且好几个模块都要用的东西。流程外（后端）不能直接用这里。

| 位置 | 作用 | 谁用 | 现在的状态 |
|---|---|---|---|
| prompt.mjs | 读模块文件夹里的 prompt.md，带版本号、填变量；实现挪到了 backend/共用/工具/提示词.mjs，这里转出 | 用到 AI 的模块 | 能用 |
| 网址键.mjs | 对比是不是同一个网址：不分 http/https，去掉 www、结尾斜杠、锚点、跟踪参数 | 02、记拒过的网址 | 能用 |
| 拒过.mjs | 丢弃候选时顺带提一条“拒过的网址”改动，30 天内 02 遇到就扔 | 03、05 | 能用（05 已接上，03 还是空壳） |
| candidate.mjs | `合成记录(data)`：把 04 的抽取结果并进候选，合成一条用新库字段名的记录（交给程序审核、三项核验） | 05 | 能用 |

读网页也不在这里：维护已有记录也要读网页，所以抓网页放在美国下一级的 `../web/`，模块经 `../web/index.mjs` 用（运行时由总控通过 `ctx.web` 交给模块）。
调 AI 不在这里：模块通过 `ctx.ai.chat()` 用 AI 总管（`backend/美国/ai/`），提示词和返回格式放在模块自己的文件夹里。
规矩：这里不引用任何模块。
