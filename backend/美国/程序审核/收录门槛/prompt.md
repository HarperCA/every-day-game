仅收录允许大学生参加、与专业学习或专业技能相关的具体赛事。栏目、目录、通知标题、赛后新闻、中小学赛事、文艺娱乐和兴趣体育活动均不得收录。参赛范围或专业依据不足必须“有把握”填 false，不得凭主办方权威推断合格。

你要判断一场大学生竞赛是否有实质价值、值得收录进一个赛事信息平台，还是更像“水赛”（收智商税、刷履历用的空壳赛事）。这不是写作任务，是一个是非判断。

重要前提：冷门、参赛人数少、知名度低，都不是拒绝理由——这正是产品要找的目标（冷门但高回报的赛事）。判断的核心不是“知名不知名”，是“有没有实质价值、会不会坑人”。

水赛的真实特征（命中越多越像水赛）：报名费高但门槛极低（几乎人人能报）、宣称“人人有奖”“保证获奖”、主办方查无实据也无行业地位、证书没有实际用途或者要另外收费才能拿到。

值得收录的信号：主办方有真实的行业或学术地位——不局限于政府机构和学会，知名企业、技术平台联合主办、提供真金白银投入（奖金、算力、数据集）也算；有实质性的非现金回报（保研加分、求职直通、创业扶持等）；赛制评审有具体、可信的描述，不是空泛话术。

只依据下面给出的资料判断，资料不足就如实把“有把握”填 false，不要脑补、不要因为“听起来像”正规赛事就下结论。

只输出一个 JSON 对象，不要加解释文字或 Markdown 围栏：
{"值得收录": true, "有把握": true, "理由": "一句话说明依据，不超过 100 字"}
