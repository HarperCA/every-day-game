# 发布门槛

`查发布(记录, { 归档 })` → 通过 / 不通过和所有原因。归档只查标题、范围、名称。另给 `报名时间问题`、`名称混了年份届次`、`有核验过的官方来源`、`有高校转发来源`、`信息来源`。

2026-11-12 用户定放宽两条：

- 官方来源核过一次就算（有核对时间就行），不要求发布前 24 小时内复核。
- 缺报名网址时，有核验过的官方来源就不拦。门槛只判断、不改记录；`报名网址顶上(记录)` 交回记录里的报名网址，没有就交回核验过的官方来源网址（主办方通知优先），由发布、写入的地方填进去（06 入库新建届次时用它）。

2026-11-12 用户定（找新一届）：发现新一届就发布，追不到官方通知的用高校转发发布、标明来源。

- 高校转发来源：`source_type` 是 `school_repost`、`validity_status` 是 `valid`、http(s) 网址、属于这一届（`is_official` 是假的，不算官方来源）。
- 没有核验过的官方来源、但有高校转发来源的届次：“没有核验过的官方来源”“没有报名网址”两条放行；标题、范围、名称、报名时间照查。
- `报名网址顶上` 不拿转发页（转发页不是报名入口）。
- `信息来源(记录)` → `official`（有核验过的官方来源）/ `school_repost`（只有高校转发的）/ `null`（都没有）。公开同步推给北京的 `info_source` 是从来源表按同样的意思推的（见 `沟通/公开比赛同步/格式.mjs`）。
