# 各家接口（ai/providers）

每家一个文件夹，只放“怎么和这家打交道”的特有部分：拼请求、解析返回、把报错归到统一类型。重试、暂停、补位、记账都在 `../common/call.mjs`，不在这里。

| 文件夹 | 会的能力 | 用在哪些用途 | 状态 |
|---|---|---|---|
| deepseek/ | 对话、搜索 | 抽取、收录再判、判重、赛事助手；搜索补位第三家 | 能用（10-30 真实试过） |
| kimi/ | 对话、搜索、读网页 | 审核、三项核验；搜索补位第二家；空壳页重读 | 能用（10-30 真实试过） |
| baidu/ | 搜索 | 搜索补位第一家，每天自动 30 次 | 能用（10-30 真实试过） |
| jev/ | 判断 | 候选分类、挑链接 | 能用（10-30 真实试过） |
| codex/ | 对话（本机命令行） | 通知追溯 | 能用（10-30 真实试过） |

对外：每家导出 `name`、会的能力函数（`chat`、`search`、`fetchPage`、`decide` 里的几个）、`classifyError`；不用密钥的导出 `needsKey = false`。
