# AI 总管的复用部分（ai/common）

每家接口都要经过的部分，只写一份。

| 文件 | 作用 | 现在的状态 |
|---|---|---|
| errors.mjs | 统一的错误类型（8 种）和哪些能重试 | 能用 |
| session.mjs | 带身份的会话：来源、运行编号、模块、车道；对外有 chat()、search()、fetchPage()、decide()、budgetLeft() | 能用 |
| call.mjs | 分发和调用流程：按用途选能力、接口和模型 → 排队 → 暂停、每天次数检查 → 超时 → 重试 → 连续失败暂停 → 记账 → 一家失败换下一家补位 → JSON 解析 | 能用 |
| http.mjs | 各家共用的发请求：POST JSON、超时、HTTP 错误归类、搜索结果统一格式 | 能用 |
| keys.mjs | 读 AI 密钥：只有这里能读，日志里打码 | 能用（环境变量 AI_KEY_<接口名> 或密钥目录里的 <接口名>.key） |
| usage.mjs | 记账和汇总：当场记、按模块、按晚、按天；今天某家成功调用了多少次（每天次数上限用） | 能用 |
| config.mjs | 用途对应哪种能力、哪家（可多家补位）、哪个模型；车道；每天次数上限；价格 | 结构定了；DeepSeek、百度、Jev 价格和车道额度待定 |

规矩：这里不引用 `../providers/` 以外的东西去发请求；不放任何具体任务的提示词或处理逻辑。
