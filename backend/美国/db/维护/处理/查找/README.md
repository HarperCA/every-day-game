# 查找

缺失的信息，或者知道错了但不知道正确值的（比如链接打不开），调工具去查。

- **现在会处理的**：缺失字段检查交来的问题——交给 Codex 补字段（`美国/补字段/`，2026-11-03 用户定）。Codex 搜索、读主办方网页（旧系统 trace-drafts、organizer-watch 做的事），程序核对每个值都在读过的官方原文里。
  - 补到的：交回改动和出处，分流后直接改，后台记录（维护改正）留出处
  - 官方写“待公布”的时间：届次标待公布
  - 都没补到：留着，下次轮到再查
  - **已发布、报名还没截止、却补不到报名时间**：转人工审核（学生正要报名，缺时间不能等）
- **还不会处理的**：别的检查项交来的（链接打不开、新一届等），交回“没找到”并写明原因，等那几项做好再接。
- **花费**：Codex 走包月订阅；搜索先用百度（占每天 15 次），用完换 Kimi、DeepSeek。
