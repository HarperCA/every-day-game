# 维护（美国/db/维护）

**维护比赛库现在由 `../新维护/` 做**（每天 10:00 一批，后台多选的比赛排进维护队列由它的队列模式处理），见 `../新维护/README.md`。
这个文件夹只剩**每日归档**（`归档/`）和手动跑的**批量归档**（`批量归档/`）。

## 每日归档

`归档/` 每天 2:00 自己跑一次（定时器 `competition-radar-archive`）：报名已截止的已发布届次全部归档，算下一届预计，见 `归档/README.md`。
它像外人一样只经 `db/index.mjs` 用比赛库；比赛库本身不反过来引用它（`db/test/单独/structure.test.mjs` 检查）。

## 批量归档

`批量归档/` 手动跑（2026-11-12 用户定）：每个比赛最新一届、还是待人工审核、报名已截止（没写截止看比赛结束）的改成已归档，要过发布门槛的归档那几项，人工定过状态的不动；支持 `--试跑`，见 `批量归档/README.md`。

用户原话：“这套 AI 审查（Codex，手动勾选）把这一套删掉，这一套使用新维护进行替代，然后就是可以选择任意数量的比赛进行手动勾选”。删掉的有：
