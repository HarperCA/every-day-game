# 核对原文（AI 审查）

Codex 联网查这一届的官方来源，程序重新读网页、逐字核对，核不到的不算（2026-11-05、11-06 用户定）。

- **只调 Codex**：AI 总管用途 `audit`，开 Codex 内置搜索；读网页用 `美国/web` 自己的程序。不用百度、Kimi、DeepSeek。2026-11-06 线上实测 `codex exec -c web_search="live"` 可用，查一条约 50 秒。
- **看哪些**：每次一个比赛（`ctx.范围`）：待人工审核、已发布、最新一届，最多 3 届。没给范围不做全库审查。
- **搜索轮次**：每届最多 3 轮，每轮单独起一次 Codex、只搜 1 次，结束时写摘要（搜索进度、下一轮从哪里开始）交给下一轮，下一轮不带上一轮的全部内容（2026-11-06 用户定）。Codex 命令行没有限制搜索次数的选项，程序边收事件边数（搜 1 次、打开 5 个页面，配置 `codexSearchLimit`），超了结束进程，这一轮作废但占轮次；被结束的那轮用量没有记录。几轮核到的字段由程序合起来，只收来源性质写官方的那几轮。接口出错的重试（AI 总管）不算轮次。
- **按名称搜**：不把库里的官网、报名入口、来源网址交给 Codex，让它按名称、届次、年份搜新网页；不是官方的页面直接放弃，不追附件、不查人、打不开不重试（2026-11-07 用户定）。旧网址和新结果的对比由程序做。
- **发布前查重**：同名比赛下已有同一届已发布、已归档的，进回收站，写明和哪一届重复（2026-11-07 用户定，照旧系统）。年份有重叠就算同年，届次或赛道两边都写了且不同的不算。已经公开的不受影响。
- **屏蔽名单**：内置和后台确认的屏蔽网站（含子站）不当依据，已有的这类来源也不计入发布门槛。2026-11-06 第一次真实运行时 AI 把 52jingsai 的子站当官方，发布了创研杯，约 5 分钟后撤回。
- **核对**：`补字段` 的 `核对一项`、`核对待公布`：网页读过、原文在网页里、日期是同一天。和这一届年份差一年以上的日期不采用。

已发布和已归档的 AI 不改状态（不转待审、不撤下），要删只能进回收站：2026-09-29 旧 AI 审核撤下过 24 条已发布的比赛。

## 怎么改

- 时间和原文不一致的改成原文的；文字、主办方、专业只补空的，有内容的不覆盖。
- 报名入口和官方原文不同时（2026-11-06 用户定）：待审的换成官方的；已发布、已归档的只在旧链接 404/410 或在屏蔽名单时换，其余只记下给人看。403、超时、网络错误不算打不开：常见的是网站拦爬虫，或美国服务器连不上国内网站。人工改过的不换。新链接必须出现在读过的官方网页里，且不在屏蔽名单。旧值留在“维护改正”记录里。
- 名称不自动改，写进理由给人看。
- 人工改过的字段（`manual_fields`）不碰；人工定过的状态 AI 不改。

## 出错

额度用完、接口超时等抛给调用方，这一项算失败，不记维护时间（`../../批量.mjs` 决定停不停）。Codex 交回的内容用不了只记下，这个比赛还算维护过。
