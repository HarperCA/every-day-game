# 结构：建表和改表

按编号排的 SQL 文件，只增不改：

```
001-建表.sql      按 描述/ 生成全部表
002-….sql         以后加字段、加索引就新增一个文件，写清楚为什么改
```

`openDb()` 打开主库时，把还没执行过的编号按顺序补执行，执行过的编号记在库里的 `schema_version` 表。
线上主库有真实数据，不能删了重建，所以改表一律新增文件；线上和本地按同一串编号走，结构始终一致。

`描述/` 改了字段之后，要新增一个结构文件；测试会对照两边，对不上就失败。
