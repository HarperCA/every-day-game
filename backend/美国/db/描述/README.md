# 描述：库长什么样

每张表一个文件（在 `表/` 里按用途分组），只写数据，不写代码逻辑，也不引用别的文件（`字段类型.mjs` 除外）。
校验（`操作/校验.mjs`）、建表语句（`结构/`）、给人看的字段说明都从这里读，规则只写一遍。

```
描述/
  index.mjs          把全部表汇总成 TABLES（顺序就是建表顺序，被指向的表在前）
  字段类型.mjs        所有表共用：允许的字段类型；长度上限的几档（短 200、中 2000、网址 1000、摘录 20000）
  表/                 每张表一个文件，按用途分组
    比赛数据/          每晚流程写、小程序读
      比赛.mjs         competition   一级：比赛
      届次.mjs         edition       二级：届次，挂在比赛下
      来源.mjs         source        每条信息出自哪个网址、原文摘录
      处理记录.mjs      process_log   AI 和系统对某一届做过什么（旧记录里挂在每届身上）
    后台/
      后台记录.mjs      audit_log     后台的操作记录
  test/               测这个文件夹：字段写得对不对、旧字段都有去处
```

新加一张表：在 `表/` 对应的组里加一个文件，再在 `index.mjs` 里按建表顺序加进去。

## 每个字段怎么写

```js
name: { 说明: '比赛名称', 必填: true, 类型: '文字', 最长: null },
```

- `必填`：true 必须填，false 可以不填。
- `类型`：只能用 `字段类型.mjs` 里有的。
- `最长`：文字的长度上限；`null` 表示还没定。
- `可选值`：只能从里面选的字段才写；`null` 表示还没定。
- `指向`：引用别的表时写表名，例如届次的 `competition_id` 指向 `competition`。
- `默认`：不填时用的值。
- `旧`：旧总表里对应的字段名，建库时按它搬；`建库/旧字段.mjs` 列了全部旧字段，测试核对每个都有去处。
