# 找官网（只搜比赛名 + DeepSeek 选 + 程序核实）

2026-11-07 用户定改法：像人一样只搜比赛名，看前 10 条里哪条是官网。DeepSeek 只做选择题，不自己联网。
2026-11-08 用户定：没官网的比赛用这个找（DeepSeek 搜索 API）；从 `new_pipeline/` 挪进新维护，由 `../维护一个.mjs` 调用。
2026-11-08 试过“没找到再加搜‘比赛名 主办单位’”：同一批随机 40 个已知官网的比赛，找对 12→14、待审 17→12，用户嫌效率低，去掉了，只搜一次；找不到的由 `../维护一个.mjs` 把最新一届转待人工审核。

## 试过的几种（同样 20 个比赛，其中 11 个已知官网）

| 做法 | 已知官网对上 | 每个比赛 |
|---|---|---|
| 方案三（百度、Kimi 搜，程序打分，已删） | 3/11 | 约 800 token |
| DeepSeek 自己联网问（用途 `official_online`，11-08 删了） | 10/11 | 约 1.5 万 token |
| 本版：DeepSeek 搜索 API 只搜比赛名 → DeepSeek 选（11-08 本地实测） | 5/11 | 约 2400 token + 1 次搜索（0.00075 美元） |

本版没对上的 6 个：4 个的官网不在搜到的 20 条里（传智杯 3 个、华灿奖），1 个在第 17 条（传智杯 AIoT），1 个选了别的页面（土地整治）。
官网在前 10 条里的 6 个，DeepSeek 选对 5 个。结果和脚本在本地 scratchpad 效果测试/新找官网结果.json、对比新.mjs。

## 步骤

1. 只搜比赛名（AI 总管用途 `official_search`：DeepSeek 搜索 API `/v1/tools/search`，要 20 条）；去掉屏蔽网站和重复网址，留前 10 条。
2. 把这 10 条（标题、网址、网站名、日期、权威等级、摘要前 200 字）交给 DeepSeek 选（用途 `official_pick`，要 JSON：`{"选":序号,"理由":""}`，都不是填 0）。问题里有比赛名称、别名、主办方、要哪一届、教训（`问题.mjs`）。
3. 程序检查，哪一步不过就停：
   - 搜不到、搜到的都是屏蔽网站、没按格式回答、选 0、序号不对 → **待审**；
   - 打开它选的（`核实.mjs`）：打不开 → **网络问题**（记下网址，以后按频率重读）；页面文字加上搜索结果的标题、摘要里有比赛名称 → **找到**（网页加载后才显示内容的页面，读到的文字里常没有名称）；都没有 → **待审**。
   - 年份、主办单位只记下来（`年份对上`、`主办单位对上`、`有新一届`），不卡。
4. 交回要写回搜索记忆的改动（`记忆.mjs`）：找到写官方域名、搜索词（比赛名）、通知标题格式；没找到写一条教训（最多 3 条）。

AI 出错（额度用完、余额不足、对方出错）照样抛出，交给调用方顺延。

## 用法

```js
import { 找官网, 写回记忆 } from './index.mjs';
const 回 = await 找官网(比赛, { ai, 读网页, 节, 目标: { 年份: 2027, 届次: null, 已知年份: 2026 }, 屏蔽 });
// 回：{ 结果: '找到'|'网络问题'|'待审', 官网, 打不开, 原因, 记忆改动, 调用: { 搜索, DeepSeek, 打开 }, 用量, 过程 }
写回记忆(db, 比赛.id, 回.记忆改动, { 操作人 });
```

只查不写：写比赛库（搜索记忆、状态）由调用方决定。试跑（要有密钥）：

```bash
node backend/美国/db/新维护/找官网/试跑.mjs --比赛 <编号> [--年份 2026] [--届次 第十八届] [--写记忆]
```

## 文件

| 文件 | 做什么 |
|---|---|
| index.mjs | 找官网：搜、选、核实、记忆改动；写回记忆 |
| 问题.mjs | 给 DeepSeek 的选择题 |
| 核实.mjs | 名称的几种写法；打开页面核实 |
| 记忆.mjs | 搜索记忆的改动、写回；`维护记录改动(节, 一行)`（2026-11-08：给新维护用，每次维护记一行，最新在前，只留 5 条） |
| 试跑.mjs | 命令行试跑；算目标、下一届 |
