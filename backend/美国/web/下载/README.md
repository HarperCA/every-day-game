# 下载

只提供函数，由 `读网页` 调用。

- `下载(网址, { signal, 超时, 最大字节, 最多跳转, 跳转前检查 })` → `{ finalUrl, httpStatus, contentType, body }`；出错抛 `下载出错`（kind：超时、太大、网络错误、HTTP错误、不支持的类型、网址不安全）。总时长 20 秒、最大 8MB、最多跳转 5 次，跳转不自动跟，每一跳之前调 `跳转前检查`。
- `robots.mjs`：`规则允许(文本, 路径)`、`建robots检查({ fetchImpl })`、`robots允许(网址)`。每个网站的 robots.txt 只取一次；取不到、或者交回的是网页，按惯例算允许。
