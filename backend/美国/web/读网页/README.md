# 读网页（总函数）

抓网页唯一的总函数，统一管整个流程，按顺序调 `../下载/`、`../编码/`、`../正文/`、`../pdf/`、`../word/`。流程和状态见上一级 README。

```
读网页/
  index.mjs   读网页(网址, 选项)；内容类型()
  网址.mjs    网址规范化（只去掉跟踪参数）、网站键
  安全.mjs    只读公网 http/https，内网、本机地址拒绝
  限速.mjs    同一网站两次下载至少隔开 1.5 秒，进程里共用
  结果.mjs    统一结果的格式、状态、检查、哪些能下一晚再试
  源码.mjs    取源码：只拿网页源码（新维护的爬虫脚本用）
  北京兜底.mjs  带北京兜底：网络问题读不到时改请北京代读一次（2026-11-09，见 沟通/代读网页/README.md）
  浏览器.mjs  建浏览器：给 ../浏览器/ 包上安全检查；只启动一个 Chromium（记住启动的 Promise，并发都等它；
              启动失败或浏览器断开就忘掉，下次重启；关() 等启动完再关）
```
