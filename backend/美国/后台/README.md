# 后台界面（backend/美国/后台）

管理员用的网页，由美国服务器提供。**框架管外壳，每个功能一个文件夹，功能背后是三个函数**：

| 文件 | 跑在哪 | 做什么 |
|---|---|---|
| `数据库.mjs` 的 `取(参数, { db })` | 美国服务器 | 从比赛库等地方取原始数据 |
| `整理.mjs` 的 `整理(原始, 条件)` | 浏览器（纯计算） | 整理、筛选、排序、分组；不碰界面、不碰数据库 |
| `呈现.mjs` 的 `呈现(容器, 数据, 控制)` | 浏览器 | 把整理好的数据画成界面 |
| `index.mjs` | 浏览器 | `定义功能({ id, 标题, 说明, 初始条件, 整理, 呈现 })` |

框架按顺序调用：浏览器 `请求(功能)` → 服务器 `接口.mjs` 找到这个功能的 `数据库.mjs` → `取()` → 交回浏览器 → `整理()` → `呈现()`。
筛选条件变了只重新整理和呈现（`控制.改条件()`），不重新取数据；要重新取用 `控制.重新读取(参数)`。
不该重画的小请求（编辑框里先存图片）用 `控制.发请求(参数)`，只交回结果。
保存、删除这类动作用 `控制.提交(参数)`：交给 `取()` 先做动作再交回新数据，成功后重画（筛选条件不变）；失败时把错误抛回来，界面不清空。

## 加一个功能

1. 在 `功能/` 下建文件夹，写 `数据库.mjs`、`整理.mjs`、`呈现.mjs`、`index.mjs`。
2. 在 `功能目录.mjs` 登记，在 `目录清单.mjs` 放进某个分类，成为它下面的一个子页面。

## 规矩（由 test/单独/frame.test.mjs 检查）

- 浏览器那边的文件拿不到服务器的代码：不引用 `数据库.mjs`、`接口.mjs`、`服务.mjs`、`每日清理.mjs`，也不引用 `后台/` 以外的文件；服务器也不把这些文件发给浏览器。
- `数据库.mjs` 只用比赛库的入口（`美国/db/index.mjs`）和同文件夹的文件。
- `整理.mjs` 是纯计算：不引用任何文件，不碰页面和网络。
- 只有 `框架/请求.mjs` 发网络请求。

## 本地运行

```bash
node backend/美国/后台/服务.mjs
```

然后打开 http://localhost:4318 。比赛库用默认位置，第一次打开会建空库（`backend/美国/db/数据/比赛库.db`，不进 git）。

## 登录（2026-11-03）

美国服务器上挂在 https://107-175-111-18.sslip.io/new-admin/（nginx 去掉前缀转到本机 4318），所以网页里的地址都写相对的（`./api/…`、`./海报/…`）。
设了 `ADMIN_TOKEN` 或 `ADMIN_TOKEN_FILE`（服务器上指向旧后台的口令文件，口令和旧后台一样）就要先登录：取数据、看海报都要会话 cookie（12 小时，HttpOnly、Secure、SameSite=Strict），口令连错 5 次 10 分钟内不让再试；界面文件不用登录（里面没有数据），服务器端的文件不给。本机预览不设口令，不用登录。
服务器部分在 `建服务.mjs`、`登录.mjs`，`服务.mjs` 只负责准备环境、起服务；浏览器那边 `框架/请求.mjs` 收到“要先登录”弹 `框架/登录框.mjs`。
