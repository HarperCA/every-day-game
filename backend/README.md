# 后端（backend）

后端分成三块：美国服务器、北京服务器、两台之间的沟通；另有两边都用的共用部分和装库的配置。

```
backend/
  美国/          美国服务器：比赛库（比赛、届次、来源、处理记录、后台记录）、寻找新比赛的流程、维护已有记录、抓网页、AI 总管、后台界面
  北京/          北京服务器：用户库（账号、收藏、提醒、纠错提交、公开副本）、小程序要用的 5 项服务
  沟通/          两台之间的来往：公开比赛同步（美国→北京）、用户数据同步（北京→美国）、代读网页
  共用/          两边都用的：数据库读写方法、基础工具（并发、额度、日志、打开 SQLite）、测试工具
  Environment/   装的第三方库、要设的环境变量、测试配置
```

| | 美国服务器 | 北京服务器 |
|---|---|---|
| 跑什么 | `美国/`、`沟通/` 里的美国端 | `北京/`、`沟通/` 里的北京端 |
| 数据正本 | 比赛库 | 用户库 |
| 副本（只读） | 用户库的副本 | 已公开比赛的副本 |

两台服务器都部署整个 `backend/`，各自只启动自己那部分；`共用/` 只写一份，不复制。

## 引用规矩（由各自的 test/ 检查）

- `美国/`、`北京/` 只能用自己的文件和 `共用/`，互相不引用；
- `沟通/` 可以用 `共用/` 和两边数据库的入口（`美国/db/index.mjs`、`北京/主数据库/index.mjs`、`北京/副数据库/index.mjs`）；
- 用数据库一律经入口：`共用/db/index.mjs`、`美国/db/index.mjs`、`北京/主数据库/index.mjs`、`北京/副数据库/index.mjs`。

## 装库、跑测试

```powershell
cd backend/Environment
pnpm install --ignore-workspace    # 第一次用时装库
pnpm test                          # 跑全部测试
```

有代码要测的文件夹里有 `test/`，只测这个文件夹的代码：`test/单独/` 是测试，`test/复用/` 是共用的测试工具。
