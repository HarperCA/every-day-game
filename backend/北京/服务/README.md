# 北京的服务（北京/服务）

接替上海云开发：小程序只连北京（备案域名 xiaohuiworks.cn），每项服务一个文件夹。
上海的 publicSync（接收同步）、pageRelay（代读网页）和新写的“同步到美国”是两台服务器之间的来往，放在 `backend/沟通/`。

| 文件夹 | 做什么 | 接替上海的 |
|---|---|---|
| 登录/ | 小程序登录：用 wx.login 拿到的 code 向微信换 openid，没有账号就建一个，交回签名的会话。 | login |
| 用户数据/ | 收藏和取消、设和取消提醒、偏好、提交纠错和意见反馈、查自己的记录。收藏、提醒用主数据库核对比赛和届次在不在。 | userData |
| 公开数据/ | 小程序首页的比赛列表（筛选、排序、分页一次交回）和详情页，从主数据库读。 | publicData |
| 发提醒/ | 到时间的提醒发订阅消息；保存提醒时按到期时间排好，不靠每几分钟扫一遍。美国推来的报名时间变了，就调整已设的提醒。 | sendReminders |
| 收集报错/ | 收小程序上报的报错和加载统计，只收白名单里的字段，不收身份。 | clientLog |

上海原来还有 adminData（后台，现在走美国）、userMigrate（一次性迁移），北京不接。
