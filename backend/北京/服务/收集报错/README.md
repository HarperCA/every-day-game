# 收集报错（北京/服务/收集报错）

收小程序上报的报错和加载统计，只收白名单里的字段，不收身份。

- **接替**：上海云函数 clientLog
- **读写的数据**：收集报错自己的库文件 `DB_DIR/报错日志.db`（`报错库.mjs`）：报错日志（client_issues）、统计（client_stats），字段名照上海。
  不放副数据库：副数据库是用户管理中心，每张表都挂在用户下（2026-11-01 定）；报错和加载统计是匿名的。
- **现在的状态**：能用，有测试（2026-11-02）。清洗规则 `sanitize.js` 和它的旧测试原样搬来；统计的“加一”给公开数据服务记加载成功次数用。
- **还没做**：同步到美国给后台“访问异常”页（等两台之间的同步）。

## 要搬过来的

- 上海云函数 clientLog（已搬）

## 规矩

- 只通过 `index.mjs` 里的 `handle(request, ctx)` 和外面打交道。
- 读写数据库只经 `../../主数据库/index.mjs`（公开副本）、`../../副数据库/index.mjs`（用户管理中心）；不直接引用美国的代码。
- 不收、不存客户端传来的 openid，身份一律由服务端核验。
