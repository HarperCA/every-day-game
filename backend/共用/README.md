# 共用（backend/共用）

美国、北京两边都用的代码，只写一份。这里不放任何一边独有的东西（具体的表、一边独有的业务规则都不在这里）。
两边都用的业务规则只有一套：推荐排序（首页列表在北京、赛事助手在美国，2026-11-01 用户定放这里，只写一份）。

```
共用/
  db/          数据库的读写方法：打开、读、筛选、写、校验、版本核对、只读副本、建表生成、升级；字段类型和长度上限
  工具/        基础工具：并发池、额度、日志、打开 SQLite
  推荐排序/    《第一步：排序规则》：搜索分块、状态分组、收藏提醒分档、截止日、综合分；外面只经 推荐排序/index.mjs 用
  test/复用/   测试工具：扫描引用（各处的引用规矩测试用）、临时目录
```

## 规矩

- `共用/` 不引用 `美国/`、`北京/`、`沟通/` 的任何文件。
- 外面用数据库读写方法只经 `共用/db/index.mjs`；基础工具直接引用 `共用/工具/` 里的文件。
- 第三方库（better-sqlite3）只在 `工具/sqlite.mjs` 里取，装在 `../Environment/`。
