# 代读网页（沟通/代读网页）

**方向**：美国 → 北京 → 国内网站

每晚流程在美国跑，政府、学校这类国内网站从美国访问不稳，由北京代读后把结果交回美国。

**怎么同步**：每次请求都带密钥；北京只读公网地址（跳转后也查），遵守 robots，用同一个爬虫身份，15 秒、3MB、5 次跳转上限。

| 文件 | 跑在哪 | 做什么 | 要搬过来的 |
|---|---|---|---|
| 美国端.mjs | 美国服务器 | 请求：每晚流程读不到国内网页时，经这里请北京代读；结果用抓网页的统一格式 | 美国抓网页层 fetcher.mjs 里“连不上、超时、403 时自动改走中转”的部分 |
| 北京端.mjs | 北京服务器 | 代读：核对密钥，按安全规则读公网网页，把正文交回 | 上海云函数 pageRelay；安全规则和 美国/web/读网页/安全.mjs 同源，搬的时候两边用同一份（放到 共用/工具/） |

- **现在的状态**：骨架占位，调用会直接报错“还没实现”。
- **规矩**：两端放在同一个文件夹里，格式和密钥规则只定一次；只经 `共用/db/index.mjs`、`美国/db/index.mjs`、`北京/主数据库/index.mjs`、`北京/副数据库/index.mjs` 读写数据库；只走服务器之间，不经过小程序。
