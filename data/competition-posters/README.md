# 比赛海报与封面

目标：清单中的每条比赛记录都有一张名称、年份和届次对应的官方海报封面。

当前：1154条记录，60张已确认封面，1094条尚未确认，尚未达到全覆盖。

## 文件位置

- `manifest.json`：全部记录、配图状态、来源及文件校验值。
- `covers/`：1920×1080封面，原图等比缩放补边。
- `originals/`：取得的官方原图（57份）；其余3份仅有网页截图，台账已注明。
- `evidence/`：无法取得原文件时保存的网页截图。
- `待补海报.md`：未完成配图的比赛。

## 检查

安装 Pillow 后，在仓库根目录执行：

```sh
python scripts/validate_competition_posters.py
python scripts/validate_competition_posters.py --require-complete
```

第一条检查现有文件、尺寸、校验值及记录完整性；第二条额外要求1154条全部有封面，缺图时返回失败。

## 素材要求

- 不用其他比赛、其他届次、合影或广告替代缺图。专项赛图片必须标明适用范围。
- 保留原图，适配版不裁剪、不重绘文字。
- “有候选图”和“现有素材未找到”均不代表官网没有海报。
- 图片版权归原权利人；本仓库的代码许可不授予这些图片的商业使用或再分发权。
- 该目录是素材归档，未部署服务器或上传小程序。
