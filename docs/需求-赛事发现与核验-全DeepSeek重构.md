# 需求：通知追溯（只用 DeepSeek）

## 核心

输入一篇通知，输出它背后那场比赛的官方来源和关键信息。

## 输入

每晚抓到的一批通知，多数是学校转发的选拔通知或新闻。每篇包含标题、网址、摘要。

## 三步

**1. 认出比赛**

从标题和摘要判断它属于哪种情况：
- 本身就是一场比赛；
- 校赛或赛区赛：继续追它的上级比赛；
- 不是比赛：给出结论，写明原因。

**2. 找到官方来源**

用 DeepSeek 搜索，找到主办方或组委会发布的**当届**页面。

以下都不算官方来源：
- 学校转发的通知
- 新闻、自媒体
- 百科
- 聚合平台
- 往届页面

**3. 核实信息**

自己读取这个网页，从原文里摘出以下各项，每一项都要附原文依据：
- 主办方
- 参赛对象
- 届次
- 报名时间
- 报名入口

## 输出

每篇通知给出一个结论，交给下游入库：

| 结论 | 附带内容 |
|---|---|
| 找到 | 比赛名、官方来源网址、上面各项的原文摘录 |
| 不是比赛 | 原因 |
| 找不到 | 原因 |

## 限制

- AI 只用 DeepSeek：
  - 模型：`deepseek-flash`，对话接口 `https://api.deepseek.com/chat/completions`；
  - 搜索：只能通过 `https://api.deepseek.com/anthropic/v1/messages` 加 `web_search` 工具调用。结果里我们只能看到网址和标题，正文是加密的。
- 网页只能自己读，因为 DeepSeek 没有读网页的功能。服务器在美国，部分国内网站读不到。
- 每晚有时间上限（3 小时内）和花费上限。
- 没核到的不写：链接、日期、字段都不能编造或推断。
