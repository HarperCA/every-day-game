## 2. 和 `docs/赛事助手-设计.md` 的差异

那份设计是 2026-10-16 早些时候写的，之后用户又定了几件事。凡是冲突的地方，**以本文为准**：

| 那份设计 | 本文 | 原因 |
|---|---|---|
| 第一次调用只输出 JSON 条件，第二次只写推荐理由 | 用 DeepSeek 原生工具调用：模型自己决定查什么、要不要追问，最后自己写回答 | 用户要“完整的 DeepSeek AI 问答” |
| 每人每天 30 条 | 不限 | 用户 2026-10-16 决定先不限 |
| 读取用户偏好（专业、年级）“`userData` 里已有” | 前端把用户选过的专业大类随请求带上；没有年级 | 偏好里**没有年级**（`services/competitionPreferences.ts:27-45` 只有 `categories` 和省份）；而且用户数据存在上海云开发（`USER_DATA_ON_CLOUD = true`），美国服务器读不到 |
| 对话上下文另存 `assistant_sessions`，7 天过期 | 不另存。上下文直接从对话记录 `assistant_logs` 里按 `sessionId` 取最近 6 轮 | 记录本来就要全存，少一个集合；上下文以服务器存的为准，客户端伪造不了“助手说过的话” |
| 失败时退回关键词搜索 | 失败就如实告诉用户“暂时没法回答，请重试” | 体验版要看清 AI 的真实表现，不掩盖失败 |
| 接口异常时自动切 Kimi | 不切 | 只测 DeepSeek |
| 结果缓存 5 分钟 | 不做 | 测试阶段人少，没有必要 |
| 放宽条件按固定顺序由代码执行 | 由模型自己决定是否放宽，**放宽后必须在回答里说明**（写进系统提示），每次查询的参数都记在日志里 | 工具调用模式下，模型可以自己再查一次 |
| 理由里不许出现记录之外的日期和链接，违反就退回模板 | **保留**，见 5.5 | — |
| 集合名 `assistant_logs` | 沿用 | — |

## 4. 接口约定

### 4.1 请求

`POST /api/assistant`

```json
{
  "action": "ask",
  "userSessionToken": "（登录后服务器签发的会话，和 userData 一样）",
  "message": "我是计算机专业，有没有下个月能报名的团队赛",
  "sessionId": "session-3f9a…（第一次不传，之后每次带上服务器返回的值）",
  "profileCategories": ["计算机与AI"]
}
```

| 字段 | 规则 |
|---|---|
| `message` | 必填，去掉首尾空白后 1 到 300 个字 |
| `sessionId` | 可选；格式 `session-` 加 24 位十六进制；不合格就当作新会话 |
| `profileCategories` | 可选；只保留 13 个专业大类里的取值，其他丢掉 |

### 4.2 成功返回

```json
{
  "ok": true,
  "data": {
    "turnId": "turn-…",
    "sessionId": "session-…",
    "status": "answered",
    "reply": "按“计算机与AI、团队赛、一个月内能报名”帮你查到 3 场……",
    "aiGenerated": true,
    "options": [],
    "cards": [
      { "id": "edition-…", "name": "…", "editionName": "…", "eventLevel": "国家级",
        "registrationStatus": "报名中", "registrationEnd": "2026-10-28", "registrationEndNote": "", "daysLeft": 12 }
    ],
    "total": 3,
    "filters": { "professions": ["计算机与AI"], "participationFormats": ["团队赛", "个人或团队均可"], "registrationWithin": "1m" }
  }
}
```

`status` 的取值：

| 值 | 含义 | 前端怎么显示（第二步再细化） |
|---|---|---|
| `answered` | 查到了比赛 | 回答 + 卡片 |
| `empty` | 查了，0 场 | 回答（AI 会说没有，并建议放宽） |
| `clarify` | AI 在追问 | 问题 + `options` 按钮 |
| `chat` | 没有查库就直接回答了（比如拒绝跑题请求） | 只显示回答 |
| `blocked` | 用户输入或 AI 输出没通过内容安全检测 | 固定文案，`aiGenerated:false` |

- `cards` 最多 5 张，**全部由代码根据查到的记录生成**，模型输出的任何文字都不会进入卡片。
- `aiGenerated` 为 `true` 时，前端要在回答旁标“AI 生成”。

### 4.3 失败返回

`{ "ok": false, "message": "错误码" }`

| 错误码 | 什么时候出现 |
|---|---|
| `user_session_expired` | 会话过期或无效（由 `index.mjs` 的 `deriveUserContext` 抛出，和 `userData` 相同） |
| `unauthenticated` | 拿不到 openid |
| `assistant_not_tester` | 不在测试名单里 |
| `assistant_input_invalid` | `message` 为空或超过 300 字 |
| `assistant_check_failed` | 微信内容安全接口调用失败。**宁可不答**：检测不了就不处理 |
| `assistant_ai_failed` | DeepSeek 返回错误或格式不对 |
| `assistant_timeout` | 整体超过 20 秒 |
| `unsupported_action` | `action` 不是 `ask` |

每一种失败都会写一条对话记录，状态就是对应的错误码。

### 5.1 `askValidation.js`

```js
// 前端传来的参数一律不信：逐项校验，不合格的丢掉或直接拒绝。
const PROFESSION_CATEGORIES = [
  '综合/不限专业', '计算机与AI', '电子信息', '经管与商科', '生物与医药',
  '机械与自动化', '数学与统计', '材料与化工', '能源与环境', '设计与艺术',
  '人文与法学', '外语与教育', '建筑与土木',
];
const MAX_MESSAGE_CHARS = 300;
const SESSION_ID = /^session-[0-9a-f]{24}$/;

function validateAskInput(event = {}) {
  const message = typeof event.message === 'string' ? event.message.trim() : '';
  // Array.from 按“字”数，不按 UTF-16 编码单元数——表情符号算一个字
  if (!message || Array.from(message).length > MAX_MESSAGE_CHARS) throw new Error('assistant_input_invalid');
  const sessionId = typeof event.sessionId === 'string' && SESSION_ID.test(event.sessionId) ? event.sessionId : '';
  const profileCategories = (Array.isArray(event.profileCategories) ? event.profileCategories : [])
    .filter(value => PROFESSION_CATEGORIES.includes(value));
  return { message, sessionId, profileCategories:[...new Set(profileCategories)] };
}

module.exports = { validateAskInput, PROFESSION_CATEGORIES, MAX_MESSAGE_CHARS };
```

### 5.2 `tools.js`

> **2026-10-16 实现时的改动**：原稿把地区写成固定的省份清单。实际核对 `competitionValue.js` 的 `inferCompetitionRegion` 后发现，公开缓存里的地区还有“台湾地区”“华东地区”“国际”这类写法，而筛选是精确匹配，固定清单会对不上。改成和“找比赛”页一样（`pages/index/index.ts:114-116`），每次请求从读到的比赛里取实际出现过的地区值（`regionsOf`），工具定义由 `buildTools(regions)` 按这份值生成，参数校验 `sanitizeSearchArgs(raw, regions)` 也按它判断。这次没读到任何地区值时，工具里不出现地区参数。

```js
const pickEnum = (value, allowed) => (typeof value === 'string' && allowed.includes(value) ? value : undefined);
const pickEnumList = (value, allowed) => (Array.isArray(value) ? [...new Set(value.filter(item => allowed.includes(item)))] : []);

function parseArguments(rawArguments) {
  if (typeof rawArguments !== 'string') return rawArguments;
  try { return JSON.parse(rawArguments); } catch (_ignored) { return undefined; }
}

// 模型给的参数是一段 JSON 字符串。解析不了、取值不在白名单里的，丢掉并记下来（dropped），不报错。
function sanitizeSearchArgs(rawArguments, regions = []) {
  const args = parseArguments(rawArguments);
  if (args === undefined) return { query:{}, dropped:['_unparseable'] };
  if (!args || typeof args !== 'object' || Array.isArray(args)) return { query:{}, dropped:['_not_object'] };
  const query = {};
  const dropped = [];
  const keyword = typeof args.keyword === 'string' ? Array.from(args.keyword.trim()).slice(0, MAX_KEYWORD_CHARS).join('') : '';
  if (keyword) query.keyword = keyword;
  else if (args.keyword !== undefined && args.keyword !== '') dropped.push('keyword');
  const lists = { professions:PROFESSION_CATEGORIES, participationFormats:PARTICIPATION_FORMATS };
  for (const [key, allowed] of Object.entries(lists)) {
    const kept = pickEnumList(args[key], allowed);
    if (kept.length) query[key] = kept;
    if (args[key] !== undefined && (!Array.isArray(args[key]) || kept.length !== new Set(args[key]).size)) dropped.push(key);
  }
  const singles = { eventLevel:EVENT_LEVELS, registrationStatus:REGISTRATION_STATUSES, registrationWithin:REGISTRATION_WITHIN,
    region:regions, feeType:FEE_TYPES, sortBy:['time'] };
  for (const [key, allowed] of Object.entries(singles)) {
    const kept = pickEnum(args[key], allowed);
    if (kept) query[key] = kept;
    else if (args[key] !== undefined && args[key] !== '') dropped.push(key);
  }
  for (const key of Object.keys(args)) if (key !== 'keyword' && !(key in lists) && !(key in singles)) dropped.push(key);
  return { query, dropped };
}

// filterPublicRecords 的专业、参赛形式只认单个值；多选在这里先筛一遍，再交给它做其余筛选和排序。
function runSearch(records, query, now = new Date()) {
  const { professions = [], participationFormats = [], ...rest } = query;
  const subset = records.filter(item =>
    (!professions.length || (item.professions || []).some(value => professions.includes(value)))
    && (!participationFormats.length || participationFormats.includes(item.participation_format)));
  return filterPublicRecords(subset, { ...rest, page:1, pageSize:MODEL_RESULT_LIMIT }, now);
}

// 给模型看的结果：只给回答需要的字段，不给链接（回答里不许出现链接，见 assistantCore.js）。
function compactForModel(result) {
  return {
    total:result.total,
    shown:result.items.map(item => ({
      id:item.id, name:item.name, edition:item.edition_name, level:item.event_level,
      status:item.registration_status, registration_start:item.registration_start, registration_end:item.registration_end,
      registration_end_note:item.registration_end_note || '', professions:item.professions || [],
      format:item.participation_format, region:item.region || '', fee:item.fee_type,
    })),
  };
}

// 北京时间某天结束时刻距离现在还有几天（向上取整）；没有截止日返回 null
function daysLeft(dateText, now = new Date()) {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(String(dateText || ''))) return null;
  const end = Date.parse(`${dateText}T23:59:59.999+08:00`);
  return Math.max(0, Math.ceil((end - now.getTime()) / 86400000));
}

function toCard(item, now = new Date()) {
  return {
    id:item.id, name:item.name, editionName:item.edition_name || '', eventLevel:item.event_level || '',
    registrationStatus:item.registration_status || '', registrationEnd:item.registration_end || null,
    registrationEndNote:item.registration_end_note || '', daysLeft:daysLeft(item.registration_end, now),
  };
}

function sanitizeAskUser(rawArguments) {
  const args = parseArguments(rawArguments) || {};
  const question = typeof args.question === 'string' ? Array.from(args.question.trim()).slice(0, 120).join('') : '';
  const options = (Array.isArray(args.options) ? args.options : [])
    .filter(value => typeof value === 'string' && value.trim())
    .map(value => Array.from(value.trim()).slice(0, 16).join('')).slice(0, MAX_OPTIONS);
  return { question, options };
}
```

```js
// 调 DeepSeek 对话接口（OpenAI 格式）。关掉思考模式：
// 思考模式默认打开且强度为 high，慢；而且带 tools 时要求每次回传 reasoning_content，否则 400（DeepSeek 文档《思考模式》）。
const DEFAULT_BASE_URL = 'https://api.deepseek.com';
const DEFAULT_MODEL = 'deepseek-flash';
const RAW_LOG_LIMIT = 20000;

function createDeepSeekChat(env = process.env, request = globalThis.fetch) {
  const apiKey = String(env.ASSISTANT_AI_API_KEY || '').trim();
  const baseUrl = String(env.ASSISTANT_AI_BASE_URL || DEFAULT_BASE_URL).trim().replace(/\/+$/, '');
  const model = String(env.ASSISTANT_AI_MODEL || DEFAULT_MODEL).trim();
  const chat = async ({ messages, tools, toolChoice = 'auto', timeoutMs }) => {
    const startedAt = Date.now();
    if (!apiKey) return { ok:false, status:0, error:'assistant_ai_key_missing', elapsedMs:0 };
    const body = { model, messages, tools, tool_choice:toolChoice, thinking:{ type:'disabled' }, temperature:0.3, max_tokens:800 };
    try {
      const response = await request(`${baseUrl}/chat/completions`, {
        method:'POST',
        headers:{ Authorization:`Bearer ${apiKey}`, 'Content-Type':'application/json' },
        body:JSON.stringify(body),
        signal:AbortSignal.timeout(timeoutMs),
      });
      const raw = await response.text();
      let payload = null;
      try { payload = JSON.parse(raw); } catch (_ignored) { /* 供应商也可能返回非 JSON 的错误页 */ }
      const message = payload?.choices?.[0]?.message || null;
      return { ok:response.ok && Boolean(message), status:response.status, message, usage:payload?.usage || null,
        finishReason:payload?.choices?.[0]?.finish_reason || '', raw:raw.slice(0, RAW_LOG_LIMIT), elapsedMs:Date.now() - startedAt };
    } catch (error) {
      return { ok:false, status:0, timedOut:error?.name === 'TimeoutError' || error?.name === 'AbortError',
        error:String(error?.message || error).slice(0, 200), elapsedMs:Date.now() - startedAt };
    }
  };
  chat.model = model;
  return chat;
}

module.exports = { createDeepSeekChat, DEFAULT_MODEL, DEFAULT_BASE_URL };
```

### 5.5 `assistantCore.js`

（与实现一致；比原稿多了按实际数据生成工具定义，以及可替换的计时函数 `deps.clock`，方便测试超时。）

```js
// 一轮对话的完整流程。所有外部依赖（模型、内容检测、数据库）都从 deps 传进来，测试时换成假的。
const crypto = require('crypto');
const { buildTools, regionsOf, CARD_LIMIT, sanitizeSearchArgs, runSearch, compactForModel, toCard, sanitizeAskUser } = require('./tools');
const { PROMPT_VERSION, buildMessages } = require('./prompt');

const MAX_MODEL_CALLS = 3;         // 最多：查一次 → 再查一次 → 写回答
const TOTAL_BUDGET_MS = 20000;     // 整轮最多 20 秒
const PER_CALL_TIMEOUT_MS = 12000;
const MIN_CALL_BUDGET_MS = 2000;   // 剩余不到 2 秒就不再发起调用
const MAX_REPLY_CHARS = 600;
const MAX_LOGGED_ARGUMENT_CHARS = 2000;
const BLOCKED_REPLY = '这个问题我没法回答。可以告诉我你的专业、年级和想找什么样的比赛。';
const UNSAFE_OUTPUT_REPLY = '帮你查到了下面这些比赛：';

const newId = prefix => `${prefix}-${crypto.randomBytes(12).toString('hex')}`;
const clip = (value, max) => String(value ?? '').slice(0, max);

// 回答里出现的日期，必须是工具结果里有的；出现网址一律不行。违反就换成模板句子（卡片照常显示）。
const DATE_PATTERNS = [/\d{4}-\d{1,2}-\d{1,2}/g, /(?:\d{4}年)?\d{1,2}月\d{1,2}日/g];
function datesIn(text) {
  return DATE_PATTERNS.flatMap(pattern => String(text || '').match(pattern) || []);
}
// 统一成“月-日”比较：工具结果是 2026-10-28，回答里可能写成 10月28日 或 2026年10月28日
function normalizeDate(text) {
  const match = String(text).match(/(?:(\d{4})[-年])?(\d{1,2})[-月](\d{1,2})日?/);
  return match ? `${Number(match[2])}-${Number(match[3])}` : '';
}
function allowedDates(searches) {
  const allowed = new Set();
  for (const search of searches) for (const item of search.result.items) {
    for (const value of [item.registration_start, item.registration_end, item.competition_start, item.competition_end]) {
      if (value) allowed.add(normalizeDate(String(value).slice(0, 10)));
    }
  }
  return allowed;
}
function replyViolations(reply, searches) {
  const violations = [];
  if (/https?:\/\/|www\./i.test(reply)) violations.push('url');
  const allowed = allowedDates(searches);
  for (const date of datesIn(reply)) if (!allowed.has(normalizeDate(date))) violations.push(`date:${date}`);
  return violations;
}

function cleanReply(text) {
  return Array.from(String(text || '').replace(/[*#`>]+/g, '').trim()).slice(0, MAX_REPLY_CHARS).join('');
}

async function runCheck(secCheck, content) {
  try {
    const result = await secCheck(content);
    if (!result?.suggest) return { error:'no_suggest' };
    return { suggest:result.suggest, label:result.label ?? null, traceId:result.traceId || '', blocked:result.suggest === 'risky' };
  } catch (error) {
    return { error:clip(error?.message || error, 200) };
  }
}

async function answer(input, deps) {
  const now = deps.now ? deps.now() : new Date();
  const clock = deps.clock || Date.now;
  const startedAt = clock();
  const sessionId = input.sessionId || newId('session');
  const log = {
    id:newId('turn'), sessionId, openid:deps.openid, createdAt:now.toISOString(), promptVersion:PROMPT_VERSION,
    model:deps.chat.model || '', message:input.message, profileCategories:input.profileCategories || [],
    history:[], modelCalls:[], toolCalls:[], inputCheck:null, outputCheck:null,
    status:'', reply:'', replyViolations:[], cardIds:[], total:null, filters:null, options:[], elapsedMs:0,
  };
  const finish = async (status, result) => {
    log.status = status;
    log.elapsedMs = clock() - startedAt;
    // 记录写失败不影响用户拿到回答，但要在服务器日志里看得见
    try { await deps.saveLog(log); } catch (error) { console.error('[assistant] 对话记录写入失败', error); }
    return result;
  };
  const fail = message => finish(message, { ok:false, message });
  const done = (status, data) => finish(status, { ok:true, data:{ turnId:log.id, sessionId, status, ...data } });

  // 1. 用户输入先过内容安全；检测不了就不处理
  log.inputCheck = await runCheck(deps.secCheck, input.message);
  if (log.inputCheck.error) return fail('assistant_check_failed');
  if (log.inputCheck.blocked) {
    log.reply = BLOCKED_REPLY;
    return done('blocked', { reply:BLOCKED_REPLY, aiGenerated:false, options:[], cards:[], total:0, filters:null });
  }

  // 2. 上下文：这个会话最近几轮（服务器存的，不用客户端传的）
  const history = input.sessionId ? await deps.loadHistory(deps.openid, input.sessionId) : [];
  log.history = history.map(turn => turn.id);
  const records = await deps.loadRecords();
  const regions = regionsOf(records);
  const tools = buildTools(regions);
  const messages = buildMessages({ message:input.message, history, profileCategories:input.profileCategories || [], now });

  // 3. 模型 ⇄ 工具
  const searches = [];
  let clarify = null;
  let finalText = '';
  for (let index = 0; index < MAX_MODEL_CALLS; index += 1) {
    const remaining = TOTAL_BUDGET_MS - (clock() - startedAt);
    if (remaining < MIN_CALL_BUDGET_MS) return fail('assistant_timeout');
    const toolChoice = index === MAX_MODEL_CALLS - 1 ? 'none' : 'auto';
    const response = await deps.chat({ messages, tools, toolChoice, timeoutMs:Math.min(PER_CALL_TIMEOUT_MS, remaining) });
    log.modelCalls.push({ index, toolChoice, requestMessages:JSON.parse(JSON.stringify(messages)),
      ok:response.ok, status:response.status, finishReason:response.finishReason || '', usage:response.usage || null,
      raw:response.raw || '', error:response.error || '', elapsedMs:response.elapsedMs ?? null });
    if (!response.ok) return fail(response.timedOut ? 'assistant_timeout' : 'assistant_ai_failed');
    const message = response.message;
    const calls = Array.isArray(message.tool_calls) ? message.tool_calls : [];
    if (!calls.length) { finalText = message.content || ''; break; }
    // 模型这一步的原话（含工具调用）要原样放回对话，否则下一次调用对不上 tool_call_id
    messages.push({ role:'assistant', content:message.content || '', tool_calls:calls });
    for (const call of calls) {
      const name = call?.function?.name;
      const rawArguments = call?.function?.arguments;
      const loggedArguments = clip(typeof rawArguments === 'string' ? rawArguments : JSON.stringify(rawArguments ?? null), MAX_LOGGED_ARGUMENT_CHARS);
      if (name === 'search_competitions') {
        const { query, dropped } = sanitizeSearchArgs(rawArguments, regions);
        const result = runSearch(records, query, now);
        searches.push({ query, result });
        log.toolCalls.push({ name, rawArguments:loggedArguments, query, dropped, total:result.total, ids:result.items.map(item => item.id) });
        messages.push({ role:'tool', tool_call_id:call.id, content:JSON.stringify(compactForModel(result)) });
      } else if (name === 'ask_user') {
        clarify = sanitizeAskUser(rawArguments);
        log.toolCalls.push({ name, rawArguments:loggedArguments, ...clarify });
        messages.push({ role:'tool', tool_call_id:call.id, content:'{"ok":true}' });
      } else {
        log.toolCalls.push({ name:clip(name, 100), rawArguments:loggedArguments, unknown:true });
        messages.push({ role:'tool', tool_call_id:call.id, content:'{"error":"unknown_tool"}' });
      }
    }
    // 追问：本轮到此结束，问题和选项交给用户
    if (clarify?.question) break;
  }

  // 4. 组装。卡片只来自查询结果，模型写的任何文字都不进卡片
  const lastSearch = searches[searches.length - 1] || null;
  const cards = lastSearch ? lastSearch.result.items.slice(0, CARD_LIMIT).map(item => toCard(item, now)) : [];
  const status = clarify?.question ? 'clarify' : !lastSearch ? 'chat' : lastSearch.result.total ? 'answered' : 'empty';
  let reply = cleanReply(clarify?.question || finalText);
  if (!reply) return fail('assistant_ai_failed');
  log.replyViolations = replyViolations(reply, searches);
  if (log.replyViolations.length) reply = cards.length ? UNSAFE_OUTPUT_REPLY : BLOCKED_REPLY;

  // 5. 输出也过内容安全
  log.outputCheck = await runCheck(deps.secCheck, reply);
  if (log.outputCheck.error) return fail('assistant_check_failed');
  const outputBlocked = Boolean(log.outputCheck.blocked);
  if (outputBlocked) reply = cards.length ? UNSAFE_OUTPUT_REPLY : BLOCKED_REPLY;

  log.reply = reply;
  log.cardIds = cards.map(card => card.id);
  log.total = lastSearch ? lastSearch.result.total : null;
  log.filters = lastSearch ? lastSearch.query : null;
  log.options = outputBlocked ? [] : clarify?.options || [];
  const aiGenerated = !outputBlocked && !log.replyViolations.length;
  return done(outputBlocked ? 'blocked' : status, {
    reply, aiGenerated, options:log.options, cards, total:log.total ?? 0, filters:log.filters,
  });
}

module.exports = { answer, replyViolations, datesIn, normalizeDate, cleanReply, MAX_MODEL_CALLS, TOTAL_BUDGET_MS, BLOCKED_REPLY, UNSAFE_OUTPUT_REPLY };
```

要点说明：
- **为什么最后一次调用传 `tool_choice:'none'`**：前两次模型可以继续查，第三次强制它写回答，不会一直查下去。`'none'` 是 OpenAI 格式的标准取值，DeepSeek 的工具调用文档没有单独列出，**冒烟测试（第 8 节）里实测**。如果被拒，改成第三次不传 `tools`（非思考模式下可以这样做）。
- **追问时为什么直接结束**：`ask_user` 的问题和选项要交给用户回答，用户点了选项，作为下一轮的 `message` 发过来，上下文从记录里取。
- **日期检查的规则**：回答里每个“X月X日”或“YYYY-MM-DD”都必须能在工具结果的报名或比赛起止日期里找到，否则整句换成模板，卡片照常显示，`aiGenerated` 设为 `false`。不对“今天”放行，因为提示里已经要求日期只能照抄工具结果。

```js
// 测试名单：服务器上一个文本文件，一行一个 openid，# 开头是注释。
// openid 不进仓库（是用户标识），只在服务器上。文件不存在或为空 = 谁都不放行。
const fs = require('fs');

let cache = { at:0, file:'', set:new Set() };

function readTesters(file) {
  if (!file || !fs.existsSync(file)) return new Set();
  return new Set(fs.readFileSync(file, 'utf8').split(/\r?\n/).map(line => line.trim()).filter(line => line && !line.startsWith('#')));
}

  if (!openid) return false;
  if (cache.file !== file || now - cache.at > CACHE_MS) cache = { at:now, file, set:readTesters(file) };
  return cache.set.has(openid);
}
```

```js

const db = cloud.database();
const chat = createDeepSeekChat(process.env);

exports.main = async event => {
  const { OPENID } = cloud.getWXContext();
  if (!OPENID) return { ok:false, message:'unauthenticated' };
  if (event?.action !== 'ask') return { ok:false, message:'unsupported_action' };
  if (!isTester(OPENID)) return { ok:false, message:'assistant_not_tester' };
  let input;
  try { input = validateAskInput(event); } catch (error) { return { ok:false, message:error.message }; }

    return await answer(input, {

      loadHistory:(openid, sessionId) => loadRecentTurns(db, openid, sessionId),
```

### 6.1 `apps/server/src/wechat.mjs`

在 `SUBSCRIBE_URL` 下面加一个常量，在 `WeChatClient` 类里 `sendSubscribeMessage` 后面加一个方法，并改 `createOpenApi`：

```js
const MSG_SEC_CHECK_URL = 'https://api.weixin.qq.com/wxa/msg_sec_check';

  // 文本内容安全 2.0（官方文档：小程序安全 / 内容安全 / 文本内容安全识别）。
  // 返回微信的原始结果 { errcode, errmsg, result:{ suggest, label }, detail, trace_id }。
  async msgSecCheck({ openid, scene, version = 2, content }) {
    const token = await this.accessToken();
    const response = await this.request(`${MSG_SEC_CHECK_URL}?access_token=${encodeURIComponent(token)}`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ openid, scene, version, content }),
      signal: AbortSignal.timeout(8000),
    });
    if (!response.ok) throw new Error(`wechat_http_error:${response.status}`);
    const payload = await response.json();
    // 40001 / 42001 = token 无效或过期：清掉缓存，下次重新换；这一次照样算失败
    if (payload.errcode === 40001 || payload.errcode === 42001) this.cachedToken = null;
    if (payload.errcode) throw new Error(`wechat_msg_sec_check_failed:${payload.errcode}:${payload.errmsg || ''}`);
    return payload;
  }

export function createOpenApi(client) {
  return {
    subscribeMessage: {
      send: options => client.sendSubscribeMessage(options),
    },
    security: {
      msgSecCheck: options => client.msgSecCheck(options),
    },
  };
}
```
